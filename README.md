# PN Protocol — Android

Lightweight messaging protocol layer by Rivium Push with offline-first sync.

[![Maven Central](https://img.shields.io/maven-central/v/co.rivium/pn-protocol)](https://central.sonatype.com/artifact/co.rivium/pn-protocol)

## Installation

### Gradle (Kotlin DSL)

```kotlin
dependencies {

}
```

### Gradle (Groovy)

```groovy
dependencies {
    implementation 'co.rivium:pn-protocol:0.2.1'
}
```
